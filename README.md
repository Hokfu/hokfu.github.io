# Turtlefolio

Personal portfolio for Khant Htoo Naing, an AI Software Engineer focused on building agentic AI systems with memory, reasoning loops, and production reliability.

This site highlights practical work across autonomous agent workflows, long-term memory architecture, and scalable AI SaaS microservices built with Go and Python.

## Tech

- Next.js 15
- React 19
- TypeScript
- CSS design tokens (no heavy client runtime)

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Environment

Set your deployed URL for correct SEO metadata:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

## Update content

Edit resume content in:

- `data/site.ts`
